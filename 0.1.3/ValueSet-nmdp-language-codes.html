NMDP language codes

References

This value set is not used here; it may be used elsewhere (e.g. specifications and/or implementations that use this content)

Logical Definition (CLD)

This value set includes codes based on the following rules:

  • Include all codes defined in http://terminology.nmdp.org/codesystem/language
  • Include all codes defined in urn:ietf:bcp:47

 

Expansion

Expansion performed internally based on:

  • codesystem CodeSystem - Language - NMDP v0.1.3 (CodeSystem)
  • codesystem Tags for the Identification of Languages v0.1.3 (CodeSystem)
